# Backend for the Thomson analysis browser (tsadar_browser).
#
# Deliberately separate from requirements.txt: the Streamlit app pins
# tsadar@v0.1.2 and pulls in JAX, none of which the read-only browser needs.
#
# Fully pinned, transitive dependencies included. The point of the immutable
# version tags in .github/workflows/browser-image.yaml is that a given tag
# always means the same image; a floating requirement defeats that, because two
# builds of the same VERSION would install whatever had been released in
# between. A rebuild of an old VERSION should reproduce it.
#
# Resolved for the runtime stage's interpreter and platform (CPython 3.11,
# linux/amd64 -- see docker/browser/Dockerfile). Regenerate after changing a
# direct dependency below:
#
#   pip install --dry-run --ignore-installed --report resolved.json \
#       -r requirements-browser.txt
#
# then rewrite the pins from resolved.json. Bump VERSION in the same PR.
